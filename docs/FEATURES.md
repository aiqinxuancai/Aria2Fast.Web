# 桌面功能迁移与验证范围

| 桌面能力 | Web 实现 / 差异 |
| --- | --- |
| 下载任务、多节点、RPC | 下载页和设置页；远程 RPC 使用 HTTP(S) JSON-RPC，由服务器连接 |
| 内置本地 Aria2 | Docker 安装发行版 aria2；Windows Release 下载官方 1.37.0；macOS Release 捆绑 Homebrew aria2 和依赖 |
| RSS / Mikan 订阅 | 后台轮询，支持 RSS/Atom、过滤预览、首次跳过、历史去重、作品/季度目录 |
| Mikan 新番与 AI 信息 | 季度、星期、名称浏览；字幕组详情查询 TMDB 和 AI 评析；源站结构变化可能需要更新选择器 |
| 多组 AI 服务、简介翻译 | 四种协议，多组配置；可在查看详情时自动触发 |
| AI 自动分目录 | 订阅 AutoDir 通过模型提取作品名称后建立目录 |
| AI 文件整理 | 已完成本地任务先预览、再确认改名；远程文件系统不可直接整理，改名后原 Aria2 路径记录失效 |
| PushDeer | 本应用提交的任务完成后通知；外部客户端提交的任务仍可管理，但不加入通知追踪 |
| OSS / 配置同步 | 订阅 JSON 手动备份、合并和可选定时同步；先合并远端历史再上传，已有订阅规则以本地为准，不传播删除；不导出登录与服务密钥 |
| 本地文件打开 | 浏览器取回下载根目录内已完成文件，不调用客户端资源管理器 |
| 系统主题 / 自选 | 浏览器保存 auto/light/dark，auto 跟随操作系统实时变化 |
| 桌面启动与快捷方式 | Windows/macOS 启动后打开浏览器，支持隐藏窗口的登录自启和桌面快捷方式；Docker 隐藏相关选项，不提供托盘 |

## 数据

新订阅默认下载已有匹配资源，Web 页面保存已启用的新订阅后立即检查；勾选「仅追更」才会跳过首次检查已有资源。已有订阅的选择和历史保持不变。「重新下载全部」会忽略此订阅的去重历史和首次跳过，重新提交当前 RSS 中全部匹配资源（包含/排除条件仍生效）；已从 RSS 移除的旧资源不在范围内。暂停的订阅也可手动重新下载，但不会因此启用自动追更。提交结果显示成功数量及错误；保留原始历史，不删除或强制覆盖磁盘文件，已有同名文件由 aria2 处理。订阅记录源 ID 和 URL，历史不自动截断。RPC 接受请求后、状态持久化前异常终止，仍可能出现重复提交。

导入采用合并；相同节点 ID 与 URL 不重复导入。桌面 Path、AlreadyAddedDownloadModel 字段转换为 Web 字段；没有节点 ID 的旧订阅分配到 local。跨设备导入远程节点订阅时，先创建对应 ID 的节点或调整备份。

远程路径保留远程语义。浏览器取回、改名限定为本地下载根目录下的真实文件，禁止符号链接或越界路径。账号为单管理员，不提供多用户隔离。

## 本地验证

- 17 项核心测试：RSS/Atom、重复 ID、XXE、关键词/正则、路径与 Unicode、AI URL、原子状态、桌面导入与备份历史合并。
- HTTP fixture 集成测试：认证/CSRF、RPC、任务、订阅首次跳过及去重、Mikan 解析、四类 AI 协议、备份、退出。
- Chromium：登录、添加/暂停、订阅预览/保存、番剧详情、AI 配置/测试、390px 手机五页面布局、系统/手动主题及持久化，无脚本错误。

2026-10-03 已补充 Windows 自包含发行程序与官方 aria2 1.37.0 的真实测试：HTTP 下载及 SHA256、暂停任务/全局参数重启恢复、浏览器取回与 Range、中文改名、Torrent 上传/选文件/会话恢复、Metalink 下载、远程 RPC 和错误密钥、后台完成通知均通过。真实 RPC 测试发现并修复了分块传输兼容问题，现使用带 Content-Length 的 JSON 请求。

Chromium 手机模拟（390×844，触摸）已通过界面添加真实任务、完成状态、浏览器取回文件及 SHA256 校验；桌面视口为 1440×1000。系统主题切换和手动主题持久化通过，无 JavaScript 错误。此项为浏览器模拟，尚未在实体手机上验证。

真实 Mikan 源只读测试成功读取 2026 年秋季 29 部番剧，抽样详情返回 12 个字幕组，RSS 预览返回 100 条项目；没有创建第三方内容下载或订阅。源站内容会变化，上述计数仅为当次结果。

本机未安装 Docker、没有 macOS 环境，Docker 镜像及 macOS 发行包仍待对应运行环境验证。Actions 已加入真实下载、会话恢复和手机浏览器校验，但未推送 tag 执行。TMDB、Tavily、OSS、PushDeer、真实 AI 没有提供凭据，未验证生产接口端到端调用。详细命令和证据见 TESTING.md。
